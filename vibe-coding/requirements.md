## R-18-01 未转写时列表不应显示进度条

- **状态**：已完成（v18）
- **优先级**：P1
- **用户故事**：录音结束后没有点「开始转写」，列表卡片却出现一条空的进度条，看起来像卡住了。
- **验收标准**
  1. 只有 `status === 'processing'` 的卡片显示进度条，并且宽度跟随 `progress`。
  2. 未转写卡片的右上角只有「开始转写」按钮，卡片下方不出现任何进度条。
  3. 已转写卡片仍然显示波形。
- **影响文件**：`app/src/main/assets/www/body.html`（`renderList`）
- **不做**：不改动进度回传逻辑，不改卡片布局高度。
- **实际改动**：`media` 由"非 done 就画进度条"改为三态——`done` 画波形、`processing` 画进度条、其余为空字符串。
- **验证**：录音后不点转写，列表无进度条；点转写后进度条出现并按百分比增长；完成后变波形。

## R-18-02 切换 English 后全界面生效（含配色名）

- **状态**：已完成（v18）
- **优先级**：P1
- **用户故事**：设置里点 English，只有设置面板变了英文，列表、详情、弹层、提示还是中文，配色名也没变。
- **验收标准**
  1. 切换后列表、详情页、所有弹层、toast 提示、启动页文案都是英文；切回中文能完整还原。
  2. 配色名显示 Slate / Ivory / Bean / Paper，且当前配色仍有选中态。
  3. 逐字稿正文、译文、摘要、Markdown 等**用户内容不被翻译**。
  4. 英文长文案不换行、不撑破抽屉（用省略号）。
- **影响文件**：`body.html`（`EN` 字典、`EN_RULES`、`localize`、`MutationObserver`、`applyLang`）、`extra.css`（防溢出）
- **不做**：不做逐条 `data-i18n` 标注（字典 + DOM walk 已足够）；不引入 i18n 库。
- **实际改动**
  1. `EN` 字典 270+ 条中文→英文，`EN_RULES` 处理带数字的句子（如「共 3 条录音 · 1 条已转写」「3 月 5 日」「说话人 2」）。
  2. `localize(root)` 遍历文本节点与 `placeholder/aria-label/title`；`WeakMap` 记录原文，切回中文可还原。
  3. `MutationObserver` 监听新增节点与文字变化，动态渲染、toast 自动翻译。
  4. 用户正文容器用 `SKIP_I18N` 排除；`applyLang` 里重建配色网格后补 `applyTheme` 恢复选中态。
- **验证**：中英来回切换 3 次，界面文案完全对应、无残留中文（正文除外）、无布局溢出。

## R-18-03 设置内增加转写/翻译模型管理与付费模型入口

- **状态**：已完成（v18）
- **优先级**：P0
- **用户故事**：内置模型不可换；希望自己能选不同的转写/翻译模型，也能填自己的模型直链；同时提供付费云端转写的入口。
- **验收标准**
  1. 设置里有「本地模型 · 转写模型 / 翻译模型」两个入口，弹出列表显示：模型名、说明、体积、是否已下载、是否使用中。
  2. 支持下载（带百分比进度）、切换、删除；切换后自动重建识别器，不需要重启 App。
  3. 支持「自定义模型」：填文件名 + 直链（转写再填词表直链）后可直接下载启用。
  4. 设置里有「在线能力 · 付费转写」，列出讯飞听见 / 通义听悟 / 腾讯云 ASR / Whisper API，点击用系统浏览器打开。
  5. 模型全部按需下载，APK 体积不增加。
- **影响文件**
  - 新增 `app/java/com/phonesar/notes/ModelManager.java`（清单 / 选择 / 断点续传下载 / 状态 JSON）
  - `AsrEngine.java`（按 `family` 组装 SenseVoice / Paraformer 配置，切换后重建）
  - `TranslationEngine.java`（模型文件与提示词由 `Spec` 决定）
  - `MainActivity.java`（`getModelMarket` / `selectModel` / `saveCustomModel` / `downloadModel` / `deleteModel` / `openUrl` 桥）
  - `body.html` + `extra.css`（抽屉入口、模型弹层、云端弹层）
  - `tools/make_design.py`（网页演示桥补假实现 + CHANGELOG）
- **不做**：不做模型市场远程清单（内置写死在 `ModelManager`）；不做断点续传之外的加速（多线程分片）。
- **内置模型清单**

  | 类型 | id | 体积 | 说明 |
  |---|---|---|---|
  | 转写 | `sv-int8` | 228 MB | 默认，中/英/日/韩/粤 |
  | 转写 | `paraformer-zh` | 217 MB | 纯中文，标点更自然 |
  | 转写 | `sv-fp32` | 894 MB | 高精度，吃性能 |
  | 翻译 | `hy-mt15` | 1.08 GB | 默认，翻译专用 |
  | 翻译 | `qwen25-1.5b` | 1.04 GB | 通用小模型，术语/长句更灵活 |
  | 翻译 | `qwen25-0.5b` | 469 MB | 轻量版 |

- **实际改动**：`ModelManager` 统一管理 `Spec` 与下载（主源失败自动换备用源，`.part` 断点续传）；引擎不再硬编码路径与提示词；桥接层新增 6 个方法并把进度以 `modelDl` 事件回传。
- **风险 / 已知问题**
  - 转写模型只支持 sherpa-onnx 的单文件 + tokens 结构（Whisper 这类多文件模型暂不支持）。
  - 自定义直链填错会下载失败，需给出明确提示（已提示"模型直链"未配置 / 下载失败原因）。
- **验证**：三个转写模型、三个翻译模型各下载并切换一次；删除后重新下载；自定义直链填 Qwen 的 GGUF 能正常运行；断网时提示下载失败。

## 三、非目标 / 已知限制

- 说话人分离基于声纹聚类，音色接近或抢话时可能合并。
- 转写是分片识别（静音切 4–12 秒），时间戳是片段起点，非逐字级。
- 摘要为本地首句抽取，未接大模型。
- 不支持 iOS / 桌面端；网页预览只用于看界面，不跑真实转写。
- 付费云端转写**只提供入口**，不代付、不集成 API Key。
