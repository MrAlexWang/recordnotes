变更记录

18 个版本
  1. v182026-11-15当前

    全界面中英切换 · 模型可换 · 进度条修复

    • 设置里切 English 现在整屏生效：列表、详情、弹层、提示、配色名称一起变
    • 配色名称支持英文（Graphite / Ivory / Bean green / Paper），切换后选中态不再丢失
    • 设置新增「本地模型」：转写模型与翻译模型都能下载 / 切换 / 删除，也支持填自己的直链
    • 转写可选 SenseVoice-Small int8·fp32、Paraformer-zh；翻译可选 HY-MT1.5、Qwen2.5 1.5B / 0.5B
    • 设置新增「在线能力 · 付费转写」入口：讯飞听见 / 通义听悟 / 腾讯云 ASR / Whisper API
    • 修复没点「开始转写」时列表卡片也显示进度条的问题
  2. v172026-11-15当前

    手动转写 · 搜索全文 · 话题持久化

    • 录完 / 导入后不再自动转写，卡片右上角改成「开始转写」按钮
    • 搜索支持逐字稿与译文内容，忽略空格与大小写
    • 话题与配色改存原生，重启 App 不再丢失；历史话题自动出现在筛选里
  3. v162026-11-15

    回收站 · 话题精简 · 翻译即时

    • 删除改为进回收站，设置里可恢复 / 彻底删除；示例录音删掉后不再自动重建
    • 话题只保留「未分类」，其余由用户自己添加；旧内置话题一次性归入未分类
    • 「打开」去掉底部「浏览其它位置」，只列本机受支持音频
    • 删除只删记录，不动手机里的原始音频文件
    • 多选时隐藏左滑按钮，修复收藏/重命名/删除重复显示
    • 翻译完成后立即刷新界面，不用重启
    • 修改逐字稿后旧译文自动失效，再次翻译会重新生成
  4. v152026-11-15当前

    • 摘要页去掉引擎前缀与「转写信息」整块
    • Markdown 去掉引擎前缀与页脚说明
    • 「打开」改为直接列出本机音频（只含受支持格式）
